# SWBLOG

KIMSUNGWOO의 인터랙티브 포트폴리오와 기록 공간.

## 실행과 빌드

Node.js 20 이상에서 별도 패키지 설치 없이 실행합니다.

```sh
npm run dev
npm run build
```

로컬 주소는 `http://127.0.0.1:4173`이며 정적 배포 파일은 `dist/`에 생성됩니다.
`npm run check`는 페이지의 인라인 스크립트와 공통 스크립트의 문법을 확인합니다.

## 화면 구조

- `index.html`: Index Reel Landing → 글 목록과 ASCII Signal Field → 패널형 독자 화면. 글 목록의 vertical swap, rainbow 문자, 카테고리 이미지 회전을 유지합니다.
- `css/indexReel.css`: 랜딩과 글 목록의 최종 레이어. 랜딩에는 레일, 워드마크, 로고, 메뉴 화살표만 둡니다. 워드마크는 좌우 여백에 맞춰 하단에 앉고, 글 목록은 표 형태입니다.
- 랜딩 레일(`index.html`의 `PlaceholderScene`): 글 카드들이 하나의 리본으로 이어져 3D ∞ 궤도를 돕니다. 2D 캔버스에 카드를 얇은 세로 조각으로 나눠 그려 경로를 따라 휘게 하므로, CORS 헤더가 없는 외부 이미지도 그대로 쓸 수 있습니다. 드래그·휠로 돌리면 리본에 물결이 지나가고, 포인터 주변이 살짝 부풀며, 카드 뒷면은 카테고리 색(CODING 파랑, DESIGN 노랑, LIFE 빨강)입니다. 캔버스 대신 숨은 링크 목록이 키보드·스크린리더 탐색을 맡습니다.
- `post.html`: 독립적인 글 주소. 기존 글 링크와 연결됩니다.
- `editor.html`: 기존 Supabase 인증과 작성 기능, 데스크톱·모바일 독자 미리보기.
- `preview.html`: 에디터의 본문 미리보기와 공개 레이아웃 샘플.
- `css/editorial.css`, `js/postContent.js`: 독자 화면과 미리보기가 공유하는 본문 규칙. 저장된 HTML과 Markdown을 함께 지원합니다.
- `js/signalField.js`: 현재 글 이미지를 72×42 밝기 격자로 변환합니다. 화면 밖/숨김/비활성 상태에서 애니메이션을 멈추며 최대 네 이미지의 작은 샘플을 캐시합니다.
- `js/publication2026.js`, `css/publication2026.css`: 공통 모션, 관성 있는 커서 이미지, 퍼센트 진입 장면, 표지·챕터·읽기 완료·다음 글과 모바일 목차를 연결합니다.

`node tools/test-signal-field.mjs`는 비동기 이미지 전환 경합, 캐시 상한, 이미지 실패 대체 화면 및 모션 일시정지를 검사합니다. `npm run build`로 배포용 `dist/`를 갱신합니다.

Landing의 `.page`와 `.masthead`는 카드 위의 투명한 전경입니다. 이 배경을 불투명하게 만들면 아래 카드가 가려집니다. 글 목록은 `makeWaveText`, `text-wave-anim`, `rotate_cat`, `cat_b.png`/`cat_y.png`/`cat_r.png`를 유지하며, 후순위 스타일에서 이를 끄거나 작은 도형으로 대체하지 않습니다. 모션 감소 설정에서는 애니메이션만 정지하고 콘텐츠와 탐색은 유지합니다.

본문의 일반 소제목은 한 열의 읽기 흐름으로 구성됩니다. 에디터에서 직접 삽입한 2열 섹션은 별도로 유지하며, 인용·번호 목록·이미지·코드 블록은 공통 규칙을 따릅니다. 제목과 똑같은 본문 첫 제목은 독자 화면에서 중복 표시하지 않습니다. 미리보기는 원문을 복제해 표시하며 글을 발행하지 않습니다.

## 운영

기존 Supabase 프로젝트와 공개 클라이언트 설정을 유지합니다. 새 저장소 생성은 데이터베이스 이전이나 실제 사이트 배포를 수행하지 않습니다. 인증된 저장·발행은 해당 프로젝트의 권한과 RLS 정책을 따릅니다. 외부 글 데이터, 폰트와 CDN 스크립트에는 인터넷 연결이 필요합니다.
